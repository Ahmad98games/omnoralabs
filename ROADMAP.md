# 🗺 OMNORA OS: Strategic Roadmap

Our mission is to build the most performance-optimized, high-fidelity storefront builder for the enterprise. 

---

## 🏗 Phase 1: High-Fidelity Foundation (Q2 2026)
*Targeting design precision and developer flexibility.*

- [ ] **Custom CSS Injection**: Allow developers to inject scoped CSS directly into the Shadow DOM renderer.
- [ ] **Global Theme Mirroring**: Automatic synchronization of CSS variables between the builder UI and the generated storefront.
- [ ] **AST Validation Layer**: Procedural checks to ensure component trees are valid before deployment.

---

## ⚡ Phase 2: Intelligence & Insight (Q3 2026)
*Targeting data-driven growth at the edge.*

- [ ] **Edge-Optimized Analytics Dashboard**: Zero-JS footprint telemetry processed globally via Supabase Edge Functions.
- [ ] **AI-Advisor v2**: Deep integration with Groq to suggest structural layout changes based on conversion metrics.
- [ ] **A/B Testing Kernel**: Native support for splitting component variants at the AST level.

---

## 🔌 Phase 3: The Omnora Ecosystem (Q4 2026)
*Targeting extensibility and community growth.*

- [ ] **Omnora Plugin Marketplace**: A public API for developers to publish custom blocks, themes, and AI models.
- [ ] **Marketplace UI Integration**: Direct installation of community plugins within the Store Settings panel.
- [ ] **Multi-Merchant Workspace**: Enterprise-grade management for agencies managing hundreds of Omnora storefronts.

---

### Status Legend
- `Planned`: Architecting & Research.
- `Active`: Under active development by core team.
- `Shipped`: Available in the main branch.
